# API и SPA в одном контейнере

Dockerfile собирает frontend и .NET API и раздаёт их через ASP.NET Core на порту из `PORT`. Так проверка Хекслета и опубликованный сервис используют один адрес без отдельного production-прокси для `/api` и со SPA fallback. Цена решения — совместное развёртывание frontend и backend; SQLite на бесплатном Render без постоянного диска не гарантирует сохранность данных между перезапусками.
