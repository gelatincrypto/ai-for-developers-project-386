# Учётные данные владельца задаются при развёртывании

Для единственного владельца используем вход по логину и паролю из `Owner__Username` и `Owner__Password`, а не общие учётные данные в коде или базе. Это позволяет безопасно задавать разные значения для каждой среды без регистрации владельцев, но оператор должен передать секреты через окружение/менеджер секретов; при их отсутствии вход закрыт. Сессионная cookie ограничивает доступ к управлению и контактам гостей.
