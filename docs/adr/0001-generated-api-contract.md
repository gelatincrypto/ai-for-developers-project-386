# Единый контракт TypeSpec для API

Источник HTTP-контракта — TypeSpec; OpenAPI генерируется из него, а серверные модели и абстрактные маршруты вместе с клиентским SDK — из OpenAPI. Это исключает два независимых описания API ценой необходимости запускать генераторы в порядке TypeSpec → OpenAPI → сервер и клиент. OpenAPI Generator закреплён на 7.21.0; бизнес-правила остаются в рукописных контроллерах.
